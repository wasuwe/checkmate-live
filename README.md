# CheckMate Live

สวัสดีครับ ยินดีต้อนรับสู่ CheckMate Live 👋

ที่นี่คือเว็บเล่นหมากกระดานกับเพื่อนแบบสด ๆ เปิดเว็บ สร้างห้อง ส่งลิงก์ให้เพื่อน แล้วเริ่มเล่นได้เลย ไม่ต้องสมัครสมาชิก ไม่ต้องติดตั้งอะไร

## มาลองเล่นกัน

**👉 [checkmate-live.fly.dev](https://checkmate-live.fly.dev)**

1. กด "เล่นเลย" แล้วเลือกเกมที่อยากเล่น
2. ส่งลิงก์หรือรหัสห้อง 6 ตัวให้เพื่อน
3. กด "พร้อม" ทั้งสองฝั่ง แล้วลุยกันได้เลย

## มีอะไรให้เล่นบ้าง

- **หมากรุกสากล** · **หมากรุกไทย** · **หมากฮอส** · **หมากหนีบ**
- ตั้งเวลาเล่นได้ตามใจ มีแชทคุยกันระหว่างเกม และเพื่อนคนอื่นเข้ามานั่งดูได้
- ชุดหมาก 12 แบบจากนิทานอีสป เช่น กระต่ายกับเต่า และราชสีห์กับหนู
- เล่นได้ทั้งบนคอมและมือถือ
- ถ้าสมัครสมาชิก จะตั้งชื่อและรูปโปรไฟล์ของตัวเองได้

เล่นแล้วเป็นยังไง เจออะไรแปลก ๆ หรืออยากได้อะไรเพิ่ม เปิด [issue](https://github.com/wasuwe/checkmate-live/issues) มาบอกกันได้ครับ

## ใช้อะไรทำบ้าง

- **หน้าเว็บ:** React + TypeScript + Vite
- **เซิร์ฟเวอร์:** Go คุยกับหน้าเว็บผ่าน WebSocket และเป็นผู้ตรวจกติกาทุกตาเดิน
- **ฐานข้อมูลและระบบสมาชิก:** Supabase (PostgreSQL)
- **ที่อยู่ของเว็บ:** Fly.io ขึ้นระบบอัตโนมัติด้วย GitHub Actions

รายละเอียดการออกแบบทั้งหมดอยู่ใน [DESIGN.md](DESIGN.md)
